# Contributing to PronoteXPr

Keep PronoteXPr focused on the export experience. PRONOTE communication belongs to `PronoteXP-api`; application screens belong to `ProXP`.

Before opening a pull request, verify:

- QR Code upload and decoding still work.
- Token / URL mode sends the expected payload.
- Credentials / ENT mode sends the expected payload.
- JSON export works.
- XLSX and ODS generation works.
- Split-file mode works.
- The original glass / mesh visual language remains intact.
